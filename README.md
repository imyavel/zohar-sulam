# The Zohar with Perush ha-Sulam — Russian translation

Russian translation of the Zohar — the foundational text of Jewish mysticism —
together with the **Perush ha-Sulam** commentary by Rabbi Yehuda Ashlag
(Baal ha-Sulam, 1885–1954). Translated from Hebrew and Aramaic.

**https://imyavel.github.io/zohar-sulam/**
